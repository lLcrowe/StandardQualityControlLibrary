# Contributing to SQCL

SQCL(Standard Quality Control Library)에 기여해 주셔서 감사합니다!
Thank you for your interest in contributing to SQCL!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Commit your changes (`git commit -m "Add my feature"`)
4. Push to the branch (`git push origin feature/my-feature`)
5. Open a Pull Request

## Guidelines

- Follow the existing code style and namespace conventions (`lLCroweTool`)
- Place editor-only code in `Editor/` folders with corresponding `.asmdef` files
- Add XML documentation comments for public APIs
- Test your changes in Unity before submitting

## Reporting Issues

If you find a bug or have a feature request, please open an issue on GitHub.
